# Reproducing processed datasets

This document describes the environment and commands used to reproduce the processed dataset output generated by `process.py`.

## System used

- OS: Ubuntu 24.04 compatible Linux
- Python: 3.11
- GCC: `/usr/bin/gcc`, `gcc (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0`
- G++: `/usr/bin/g++`, `g++ (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0`
- Environment manager: `uv`

## Dependency constraints

The relevant dependency constraints are declared in `pyproject.toml`:

```toml
requires-python = ">=3.10"
dependencies = [
    "numpy>=1.26,<2",
    "pandas>=2.1,<3.0",
    "scikit-learn>=1.5,<1.6",
    "mdlp-discretization @ git+https://github.com/maicondallg/mdlp-discretization.git@old-version",
]

[tool.uv]
build-constraint-dependencies = [
    "numpy<2",
]
```

The `numpy<2` build constraint is required because `mdlp-discretization` from `old-version` fails to compile against NumPy 2 headers.

The resolved versions used during validation were:

- `numpy==1.26.4`
- `pandas==2.3.3`
- `scikit-learn==1.5.2`
- `mdlp-discretization==0.3.3` from `https://github.com/maicondallg/mdlp-discretization.git@old-version`
- `mdlp-discretization` commit: `bbcf4a46f4f0facf20bd71c48c4861c2b96acadf`

## Processing configuration

The validated `process.py` configuration was:

```python
balance = 'balanced'
k_folds = 10
datasets = ['australian.dat']
```

`Dataset._transform_to_sequencial` must cast arrays to `np.int8` before saving:

```python
x_train = x_train.astype(np.int8)
x_test = x_test.astype(np.int8)
y_train = y_train.astype(np.int8)
y_test = y_test.astype(np.int8)
```

Saving string arrays changes the `.npz` dtype to unicode and produces larger files.

## Commands

Create/sync the environment from the lock file:

```bash
uv sync --locked
```

Run the processing script:

```bash
uv run python process.py
```

## Validation command

To compare the generated Australian dataset with a reference copy:

```bash
uv run python - <<'PY'
from pathlib import Path
import hashlib
import zipfile
import numpy as np

new_path = Path('keel_ds/data/balanced/processed/australian.npz')
old_path = Path('keel_ds/data/balanced/processed/australian (Cópia).npz')

def sha(path):
    return hashlib.sha256(path.read_bytes()).hexdigest()

print('new_size', new_path.stat().st_size)
print('old_size', old_path.stat().st_size)
print('new_sha256', sha(new_path))
print('old_sha256', sha(old_path))
print('file_bytes_identical', new_path.read_bytes() == old_path.read_bytes())

with zipfile.ZipFile(new_path) as zn, zipfile.ZipFile(old_path) as zo:
    new_infos = zn.infolist()
    old_infos = zo.infolist()
    print('same_member_names', [i.filename for i in new_infos] == [i.filename for i in old_infos])
    print('same_member_count', len(new_infos), len(old_infos), len(new_infos) == len(old_infos))
    print('all_member_payloads_identical', all(zn.read(i.filename) == zo.read(j.filename) for i, j in zip(new_infos, old_infos)))

new = np.load(new_path)
old = np.load(old_path)
print('same_keys_order', new.files == old.files)
print('all_arrays_equal_shape_dtype_values', all(
    new[k].shape == old[k].shape and
    new[k].dtype == old[k].dtype and
    np.array_equal(new[k], old[k])
    for k in new.files
))
PY
```
